# Лабораторная работа №2: Параллельное умножение матриц (OpenMP)

## Цель работы
Модифицировать программу умножения матриц для параллельного выполнения с использованием технологии OpenMP и провести серию экспериментов с разным количеством потоков.

## Структура проекта
- `main.cpp` — основной код на C++ с распараллеливанием внешнего цикла (`#pragma omp parallel for`).
- `generate.py` — скрипт для генерации тестовых матриц заданного размера.
- `verify.py` — скрипт для проверки корректности параллельных вычислений путем сравнения с последовательным алгоритмом.
- `result_matrix.txt` — файл с результатом работы C++ программы (генерируется автоматически).
